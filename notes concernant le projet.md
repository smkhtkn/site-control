Le projet a été préparé par Stephy et Andrei. Nous disposions d'une page d'accueil partiellement remplie, conceptuellement préparée par Jana.

Nous avons utilisé l'intelligence artificielle pour générer toutes les images de la page d'accueil ainsi que la publicité sur la page Thèses. Nous avons également utilisé l'IA pour générer les textes dans le style gossip et pour une révision finale du code (suppression des répétitions, par exemple).

Nous avons très activement utilisé les inspecteurs des navigateurs Firefox (Andrei) et Microsoft Edge (Stephy). Grâce à l'inspecteur, nous apportions des modifications brouillon afin de les transférer ensuite dans le CSS principal.

Finalement, Andrei a utilisé une approche de type « une classe = une fonction » pour réduire la taille du code CSS de 1120 lignes à 682 lignes. Cette approche permet de combiner différentes classes directement dans le HTML selon les besoins et s'avère plus pratique. Selon nous, l'efficacité du code se mesure par sa taille.

Sachant que les pages des années 2000 se chargeaient très lentement, nous avons préféré utiliser un minimum de détails sur les pages Photos et Thèses, en privilégiant une mise en page minimaliste en blocs sans éléments superflus. Stephy a également préparé les commentaires pour la moitié du CSS.

Une recherche Google limitée aux années 2005-2006 est également prévue via la Search Box, préparée par Jana.
